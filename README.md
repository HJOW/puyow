# Web Puyo

브라우저의 HTML Canvas로 만든 2D 뿌요 대전 퍼즐 게임입니다. 왼쪽은 플레이어가 직접 조작하고, 오른쪽은 CPU가 조작합니다. 이미지와 사운드 에셋 없이 도형과 색상만으로 뿌요, 방해뿌요, 예고뿌요를 표현합니다.

## 실행 방법

`webpuyo.html`을 최신 웹 브라우저로 엽니다. 메인 화면에서 `게임 시작`을 선택한 뒤, 적 선택 화면에서 상대를 고르고 `게임 시작` 버튼을 누르면 대전이 시작됩니다.

게임은 HTML에서 `WebPuyo.initialize('webpuyo_canvas')`를 명시적으로 호출해 초기화합니다. 기본 페이지에는 이 호출이 포함되어 있으므로 별도 작업 없이 실행할 수 있습니다.

## 조작 방법

| 키 | 동작 |
| --- | --- |
| 왼쪽/오른쪽 방향키 | 뿌요 쌍을 좌우로 이동 |
| 아래 방향키 | 한 칸 아래로 이동 |
| Z | 왼쪽으로 회전 |
| X | 오른쪽으로 회전 |
| ESC | 게임 중 일시정지, 일시정지 중 재개 |

일시정지 화면에서는 `재개` 버튼 또는 `ESC`로 게임을 이어서 진행할 수 있고, `종료` 버튼으로 메인 화면으로 돌아갈 수 있습니다. 게임이 끝난 뒤에는 `Enter`를 누르거나 캔버스를 클릭하면 메인 화면으로 돌아갑니다.

## 게임 규칙

- 필드는 가로 6칸, 보이는 세로 12칸이며 위에 숨김 1줄이 있습니다.
- 같은 색 뿌요가 상하좌우로 4개 이상 연결되면 폭발합니다.
- 폭발한 색 뿌요에 인접한 방해뿌요도 함께 사라지지만, 방해뿌요는 점수와 공격량에 포함되지 않습니다.
- 연쇄가 이어질수록 점수와 공격력이 커집니다. 공격은 먼저 자신의 누적 피해를 상쇄한 뒤 남은 만큼 상대의 방해뿌요 피해로 전달됩니다.
- 각 필드 최상단의 예고뿌요는 받을 예정인 방해뿌요 양을 나타냅니다.
- 보이는 최상단의 세 번째 칸에 뿌요가 있으면 패배합니다.

## 화면 안내

중앙 상단에는 플레이어와 CPU의 다음 뿌요 2쌍이 각각 표시됩니다. 중앙 중간에는 선택한 적의 초상화가, 중앙 하단에는 양쪽 점수가 표시됩니다. 뿌요가 폭발하면 해당 위치에 연쇄 수가 나타나 위로 떠오르고, 2초 뒤 사라집니다.

## AI 확장

게임 엔진은 `webpuyo.js`를 브라우저 전역 객체 `WebPuyo`와 CommonJS 모듈로 제공합니다. 별도 JavaScript 파일에서 `WebPuyo.OpponentController`를 상속하고 `WebPuyo.registerOpponent()`로 등록하면 엔진 파일을 수정하지 않고 새 적을 적 선택 화면에 추가할 수 있습니다.

AI 한 차례는 `prepareTurn(player)`, `chooseTarget(player)`, `chooseRotate(player)` 순서로 결정됩니다. `prepareTurn()`이 미리 만든 `player.aiSimulations`에는 가능한 착지 위치와 회전별 예상 공격력이 들어 있어, AI가 열과 회전을 함께 선택할 수 있습니다. 자세한 등록 방법과 API 예시는 [HOWTO_NEWAI.md](HOWTO_NEWAI.md)를 참고하세요.

## 파일 구성

- `webpuyo.html`: 캔버스를 포함한 페이지 구조
- `webpuyo.css`: 전체 화면 캔버스 레이아웃과 글꼴 스타일
- `webpuyo.js`: CommonJS/브라우저 라이브러리, 게임 상태, 규칙, 렌더링, 입력, CPU 조작
- `HOWTO_NEWAI.md`: 새로운 CPU 상대를 추가하는 방법
